# Data availability

The analysis-ready data, source code, workflow runner, software requirements,
precomputed outputs, and validation scripts used to reproduce the results of
this study are publicly available at:

https://github.com/DongheQuan1227/wildfire-seasonal-dynamics-reproducibility

A complete executed snapshot, including generated statistical tables,
manuscript figures, model outputs, out-of-fold predictions, SHAP results,
bootstrap results, SEM outputs, QA files, manifests, and workflow logs, is
provided with the v1.0.0 GitHub Release.

A permanent archival DOI will be added after the GitHub Release has been
archived.

The repository reproduces the statistical analyses, model validation, tables,
and figures from the supplied analysis-ready tables. Original MODIS,
ERA5/ERA5-Land, GEFF/CEMS, vegetation, terrain, population, land-use, and
OpenStreetMap products remain available from their cited data providers under
the providers' respective terms.
